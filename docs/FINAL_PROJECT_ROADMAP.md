## 1. Executive Vision: Moving from Diagnosis to Solution

In our initial phase, we successfully diagnosed the problem and established baseline benchmarks:
- **E1 (Human In-Distribution):** CodeBERT achieves 66.36% Accuracy / 64.71% Macro F1.
- **E2 (Zero-Shot AI Transfer):** Catastrophic collapse down to 8.23% Macro F1 due to false-positive surges on LLM-generated code.
- **SeCodePLT Benchmark:** 50.00% Accuracy (coin toss) on paired CVE patches due to sequence pooling blindness.

### The Objective of the Final Project:
We must not stop at simply showing that standard models fail on AI-generated code. The **final research paper and project** must deliver the **concrete scientific solution**:
1. **Develop Domain Adaptation Methods (E3 & E4)** that eliminate the $-56.48\%$ generalization gap and restore precision on AI code.
2. **Build a Patch-Sensitive Contrastive Classifier** capable of distinguishing 1–3 line CVE fixes on SeCodePLT.
3. **Build an Intelligent Provenance-Aware Dispatcher**: A system that automatically identifies whether code was generated by an LLM (Copilot, Claude) or written by a human, routing it to the optimal specialized detector.
4. **Produce a Camera-Ready 8-Page IEEE/ACM Publication Draft** with complete ablation studies and qualitative case studies.

## 4. Phase-by-Phase Execution Details

### Phase 1: Full Domain Adaptation (E3 & E4 on Local RTX 3050)
- **Goal:** Solve the domain collapse by fine-tuning CodeBERT directly on the partitioned AI dataset.
- **Dataset Partitioning (Already Complete):**
  - `datasets/processed/llmvul_train_clean.jsonl`: 14,631 clean samples across 216 repos.
  - `datasets/processed/llmvul_holdout_clean.jsonl`: 4,120 clean samples across 8 disjoint repos.
- **Training Runs to Execute on Local GPU:**
  - **Run A (E4 - AI-Native Model):** Train CodeBERT on 14,631 LLMVul samples $\rightarrow$ Test on 4,120 holdout.
  - **Run B (E3 - Joint Human-AI Model):** Train CodeBERT on $21,854 \text{ (Devign)} + 14,631 \text{ (LLMVul)} = 36,485$ samples.
- **Target Empirical Outcome:**
  - Recover Macro F1 from **8.23% $\rightarrow$ >75.0%**.
  - Reduce false-positive rate on AI code from **99.9% $\rightarrow$ <15%**.

---

### Phase 2: Patch-Level Contrastive Learning (Solving SeCodePLT)
- **The Core Problem:** Security patches change only 1–3 lines. Standard sequence classification pools all 512 tokens, burying the fix under 95% unchanged code.
- **The Solution:** Implement a differential Siamese encoder:
  $$\mathbf{d} = |\mathbf{h}_{\text{vuln}} - \mathbf{h}_{\text{patch}}|$$
  $$\hat{y} = \sigma(\mathbf{W} [\mathbf{h}_{\text{vuln}}, \mathbf{h}_{\text{patch}}, \mathbf{d}] + b)$$
- **Target Empirical Outcome:**
  - Elevate patch discrimination accuracy from **50.00% (coin toss) $\rightarrow$ >78%**.

---

### Phase 3: Intelligent Provenance Router (Product Feature)
- **Architecture:**
  - Lightweight stylometry classifier (TF-IDF + Ridge Classifier, <2ms inference) detecting whether code was synthesized by an LLM (Copilot/Claude style) or written by a human.
  - **Dynamic Routing:**
    - If Human $\rightarrow$ Dispatches to Human-Tuned Model (Devign weights, prioritizing recall).
    - If AI $\rightarrow$ Dispatches to Domain-Adapted Model (LLMVul weights, preventing false-positive surges).
- **Integration:** Expose via `/api/v1/scan/adaptive` and update the React frontend dashboard with an **"Adaptive Dual-Engine"** scanning toggle.

---

### Phase 4: Cross-Architecture Benchmark (CodeBERT vs. GraphCodeBERT vs. UniXcoder)
- To make the research paper suitable for top-tier conference publication (e.g., MSR, ICSE, ASE, EMNLP), we benchmark across model families:
  1. **CodeBERT:** Sequence-level BPE contextual transformer.
  2. **GraphCodeBERT:** Incorporates AST data-flow graphs and variable alignment.
  3. **UniXcoder:** Multimodal (AST, comment, code) masked autoencoder.
- **Hypothesis to Test:** Does incorporating data-flow graph structure (GraphCodeBERT) make vulnerability representations more resilient to LLM stylistic shifts?
